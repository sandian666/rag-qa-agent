# RAG 检索测试题（配合《高中数学核心知识笔记.md》使用）

> 用途：验证 RAG 的检索环节准不准。
> **每道题都标了"应该命中哪一节"** —— 检索结果里出现对应小节的内容，就说明检索对了。
> 建议每次改完切块策略/embedding 模型后，用这套题**回归测试**一遍。

## 一、题目表

| 编号 | 问题 | 应命中 | 考点 |
|---|---|---|---|
| Q1 | 判断一个关系是不是函数，关键看什么？ | 一、函数 | 基础概念 |
| Q2 | 为什么说"导数为零的点不一定是极值点"？举一个反例。 | 二、导数 | **易错概念** |
| Q3 | 闭区间上求最值，为什么端点的函数值一定要算？ | 二、导数 | **易错概念** |
| Q4 | 诱导公式的口诀是什么？意思是什么？ | 三、三角函数 | 记忆口诀 |
| Q5 | 解三角形什么时候用正弦定理、什么时候用余弦定理？ | 三、三角函数 | 方法选择 |
| Q6 | 等比数列求和时最容易漏掉哪种情况？ | 四、数列 | **易错点（公比=1）** |
| Q7 | 用基本不等式求最值时，为什么要检查"等号能不能取到"？ | 五、不等式 | **易错点** |
| Q8 | 二面角的三种做法分别是什么？ | 六、立体几何 | 方法枚举 |
| Q9 | 椭圆的 a、b、c 有什么关系？双曲线呢？这两个为什么会记反？ | 七、解析几何 | **易错点** |
| Q10 | 样本方差的分母为什么是 n 减一？ | 八、概率统计 | 概念理解 |

## 二、跨小节题（**难度更高，专门测"一次检索够不够"**）

这几道题的答案**分散在多个小节**，用来测"只检索一个块会不会答不全"。
如果模型只答出一半，说明**top_k 太小**或**切块把相关语义切散了**。

| 编号 | 问题 | 应命中（多个） | 考点 |
|---|---|---|---|
| C1 | 高中阶段有哪些地方用到"求最值"？各自的方法有什么不同？ | 二、导数 + 四、数列 + 五、不等式 | **跨 3 节** |
| C2 | 哪些知识点里有"容易记反/容易漏"的情况？ | 多处 | 检索召回广度 |
| C3 | 我想复习"怎么判断一个式子的正负"，该看哪几节？ | 一、函数 + 五、不等式 + 二、导数 | 语义联想（**不用原词**） |

## 三、负样本题（**答案不在文档里**）

用来验证"没有相关信息时，模型会不会老实说不知道"，而不是编。

| 编号 | 问题 | 预期行为 |
|---|---|---|
| N1 | 复数 i 的平方等于多少？ | **说"资料里没有"**（笔记里没有复数这一节） |
| N2 | 微积分里的"中值定理"讲了什么？ | **说"资料里没有"**（超纲） |
| N3 | 洛必达法则怎么用？ | **说"资料里没有"** |

> ⚠️ **这三题最关键** —— 它们测的不是"能不能答"，而是"**会不会不懂装懂**"。
> 如果模型硬答出来了，说明你的 prompt 约束不够，或者相似度阈值没起作用。

## 四、使用建议

1. **先跑 Q1-Q10**：这是基本盘，命中率应该接近 10/10。
2. **再跑 C1-C3**：这几个能暴露"切块粒度"和 `top_k` 的问题。
3. **最后跑 N1-N3**：验证反幻觉机制。
4. 每次调完参数（块大小 / 重叠 / top_k / 阈值 / embedding 模型），**重跑一遍记录结果**，你就能看到"哪个参数真的有用"。
