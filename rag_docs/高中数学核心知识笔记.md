## 一、函数与基本初等函数

函数的本质是一种对应关系：给定一个自变量，按某个规则，有唯一确定的因变量与它对应。所以判断一个关系是不是函数，关键就是看"一个 x 会不会对应出两个 y"。只要出现一个 x 对应多个 y，那就不是函数。

定义域是我最早忽略的东西，后来发现它是所有题的起点。做题第一步永远是先看定义域：分式的分母不能为零；偶次根号里面必须大于等于零；对数的真数必须大于零，底数必须大于零且不等于一。这三条基本能覆盖高中阶段绝大部分定义域问题。

函数的单调性是描述"往上走还是往下走"。严格来说，在某个区间上任取两个数 x1 小于 x2，如果都有 f(x1) 小于 f(x2)，就是增函数；反过来就是减函数。判断单调性有两条路：一是用定义做差，二是用导数。高一的时候只能用定义，学了导数之后就基本都用导数了，这是后面导数那一节要讲的重点。我自己老是搞混的一点是：单调性是"针对某个区间"说的，离开区间谈单调性是没有意义的。

奇偶性是描述图像的对称性。偶函数满足 f(-x) 等于 f(x)，图像关于 y 轴对称；奇函数满足 f(-x) 等于负的 f(x)，图像关于原点对称。要注意两点：一是定义域必须先关于原点对称，否则谈不上奇偶性；二是奇函数如果在原点有定义，那么 f(0) 一定等于零。

指数函数和对数函数是一对反函数，这个"互为反函数"的关系是理解它们的关键：指数函数 y 等于 a 的 x 次方，与对数函数 y 等于 log 以 a 为底 x，图像关于直线 y 等于 x 对称。指数函数一定过点 (0,1)，对数函数一定过点 (1,0)。当底数 a 大于 1 时两者都单调递增，当 a 在 0 到 1 之间时两者都单调递减。

指数运算有三条核心法则：同底数相乘则指数相加，相除则指数相减，幂的幂则指数相乘。对数运算对应的三条法则是：积的对数等于对数的和，商的对数等于对数的差，幂的对数等于指数乘以对数。这两组法则结构上是完全对应的，因为指数和对数本来就是一对逆运算。我记这两组的时候是成对记的，比单独背要牢。

函数图像变换也是常考的：左加右减是针对自变量的，上加下减是针对函数值的。也就是说 y 等于 f(x+1) 是把图像向左平移一个单位，而 y 等于 f(x)+1 是把图像向上平移一个单位。这里的"左加右减"特别容易记反，因为它是反直觉的，多画两次图就记住了。

## 二、导数及其应用

导数的几何意义是我认为最重要的一个理解：函数在某一点的导数，就是曲线在该点处切线的斜率。所以"求切线方程"这类题，本质上就是"求导数得到斜率，再用点斜式写出直线方程"。点斜式需要两个东西：一个点和一个斜率。点通常就是切点，斜率就是导数在该点的值。

导数的物理意义是瞬时变化率。位移对时间的导数是速度，速度对时间的导数是加速度。这个物理背景能帮你理解为什么导数描述的是"瞬间"的变化，而不是平均变化。

基本导数公式必须背熟：常数的导数是零；x 的 n 次方的导数是 n 乘以 x 的 n 减 1 次方；正弦的导数是余弦；余弦的导数是负的正弦；e 的 x 次方的导数还是它自己；a 的 x 次方的导数是 a 的 x 次方乘以 ln a；ln x 的导数是 x 分之一。这几条是基本功，考试时不会给你。

求导法则有两条最常用。第一条是乘积法则：两个函数相乘的导数，等于前导后不导，加上前不导后导。第二条是商的导数：分母的平方分之（分子导乘分母，减去分子乘分母导）。商的公式我经常记错符号，后来我的办法是把它和乘积法则对照着记：乘积是"中间是加号"，商是"中间是减号"。

导数的最大用途是研究函数的单调性和极值。规律很干净：导数大于零的区间上函数递增，导数小于零的区间上函数递减，导数等于零的点是"可能"的极值点。注意"可能"两个字：导数为零只是极值点的必要条件，不是充分条件，比如 y 等于 x 的三次方在 x 等于零处导数为零，但那不是极值点，那里的图像是一个"拐过去"的形状。

所以判断极值的完整流程是：先求导数，再令导数等于零求出所有可疑点，然后判断导数在这些点两侧的符号。如果左边正右边负，那是极大值；如果左边负右边正，那是极小值；如果两侧同号，那就不是极值点。

闭区间上求最值和求极值不是一回事，这是我最容易混的地方。极值只关心"局部的高低"，而最值关心的是"整个区间上最大和最小"。所以闭区间上求最值的正确做法是：把所有极值点的函数值和两个端点的函数值都算出来，然后一起比较，最大的就是最大值，最小的就是最小值。端点值一定不能漏，因为最值常常就出现在端点上。

导数还可以用来证明不等式。常见套路是构造一个新函数，把要证的不等式移项变成"新函数大于等于零"的形式，然后用导数研究这个新函数的最小值。如果最小值都大于等于零，那不等式就成立了。这个思路叫"构造函数法"，是导数大题的主流解法。

## 三、三角函数与解三角形

弧度制是三角函数的基础。180 度等于 π 弧度。引入弧度制的好处是让角度变成了实数，这样三角函数才能和指数函数、对数函数一样，成为定义在实数上的函数，也才能谈导数和图像。

三角函数的定义有两种：初中用的是直角三角形里的边长比，高中用的是单位圆上的坐标。单位圆定义的好处是能自然地扩展到任意角，包括大于 360 度的角和负角。具体说，角 α 的终边与单位圆交于点 (x, y)，那么余弦就是 x，正弦就是 y，正切就是 y 比 x。

同角三角函数的基本关系有两个：正弦的平方加余弦的平方等于一；正切等于正弦比余弦。第一个关系是由勾股定理来的，因为单位圆半径是 1。这两个关系是用来"知一求二"的，知道其中一个值，就能求出另外两个。

诱导公式的口诀是"奇变偶不变，符号看象限"。意思是：如果角度加减的是 π/2 的奇数倍，函数名要变（正弦变余弦）；如果是偶数倍，函数名不变。符号则由原角所在象限决定。这个口诀很好用，但前提是你要清楚每个象限里各个三角函数的正负号。

三角函数的图像和性质要一起记。正弦和余弦都是周期函数，周期是 2π，值域是负一到一之间，都是有界函数。正切的周期是 π，值域是全体实数，在 π/2 加 kπ 这些点上没有定义。正弦是奇函数，余弦是偶函数，正切是奇函数。

和角公式是整个三角恒等变换的枢纽。两角和的余弦等于余弦乘余弦减去正弦乘正弦；两角和的正弦等于正弦乘余弦加上余弦乘正弦。这两条公式必须记死，因为后面所有的二倍角公式、半角公式都是它们的特例。二倍角公式就是把和角公式里的两个角都取成 α，比如二倍角的余弦有三种等价写法：余弦平方减正弦平方，一减二倍正弦平方，二倍余弦平方减一。做题时用哪个形式，取决于题目里还有什么。

解三角形主要用两个定理。正弦定理是说，三角形的边长与它对角的正弦之比相等，而且这个比值等于外接圆的直径。正弦定理适合"已知两角一边"或"已知两边及其中一边的对角"的情况。余弦定理是说，某一边的平方等于另外两边的平方和减去这两边与夹角余弦乘积的两倍。余弦定理适合"已知两边及夹角"或"已知三边"的情况。

面积公式有三个层次：最基础的是底乘高除以二；用两边和夹角表示是二分之一乘以两边之积再乘以夹角的正弦；用外接圆半径表示是四倍外接圆半径分之三边之积。做题时用哪个，看题目给了什么条件。

## 四、数列

数列就是按一定顺序排列的一列数，本质是定义在正整数集上的函数。所以数列也有单调性、最值这些问题，也常常要用函数的思想去处理。我一开始没意识到"数列是函数"，后来发现很多难题都是靠这个视角打通。

等差数列的核心特征是"相邻两项的差是常数"，这个常数叫公差。通项公式是首项加上项数减一乘以公差。前 n 项和公式有两个：一个是首项加末项乘以项数除以二，另一个是 n 倍首项加上二分之 n 乘 n 减一乘公差。这两个公式要根据已知条件选着用。

等比数列的核心特征是"相邻两项的比是常数"，这个常数叫公比。通项公式是首项乘以公比的 n 减一次方。前 n 项和公式要分情况：公比等于 1 时，前 n 项和就是 n 倍首项；公比不等于 1 时，是首项乘以（1 减公比的 n 次方）再除以（1 减公比）。公比等于 1 这种情况特别容易漏，一漏就扣分。

等差中项和等比中项是最常用的性质。如果三个数成等差，中间那个数是两边数的算术平均数；如果三个数成等比，中间那个数的平方等于两边数之积。另外还有一个常用性质：等差数列中，若两项的项数之和相等，则这两项之和也相等；等比数列中，若两项的项数之和相等，则这两项之积也相等。这个性质用来化简题目非常快。

数列求和有几种方法。公式法是直接用等差或等比的求和公式。倒序相加法适用于"首尾配对"的数列，等差数列求和公式本身就是这样推出来的。错位相减法适用于"等差乘等比"形式的数列，做法是写出和式，再乘公比错开一位相减。裂项相消法适用于分式形式的数列，把每一项拆成"两个相邻项的差"，求和时中间项互相抵消。这几种方法里错位相减最容易算错，因为减的时候要注意错位和符号。

数列的最值问题经常出现。等差数列的前 n 项和是一个关于 n 的二次函数，所以可以用二次函数求最值的方法处理：看对称轴，取离对称轴最近的整数。也可以直接找"正负分界点"：当某一项从正变负时，总和就到达最大。等比数列求和的最值则要小心公比的取值范围对结果的影响。

## 五、不等式

不等式的性质是一切的基础：两边加同一个数，不等号方向不变；两边乘同一个正数，方向不变；两边乘同一个负数，方向要反向。"乘负数要变号"是最基本的坑，但仍然经常出错，尤其是在解含参数的不等式时。

一元二次不等式的解法要结合二次函数的图像来想。先看开口方向（由二次项系数决定），再算判别式判断有没有根，然后找出根，最后图像在 x 轴上方的部分对应大于零，下方的部分对应小于零。用画图的方式想，比死记"大于取两边小于取中间"要可靠得多，因为后者在开口向下时是反的。

基本不等式是最核心的工具：两个正数的算术平均数大于等于它们的几何平均数，等号成立的条件是两个数相等。用基本不等式求最值要记住"一正二定三相等"：必须是正数，乘积或和必须是定值，等号必须能取到。这三条少一条都不行，尤其是"等号能不能取到"，很多人算完最大值却不检查等号条件，那是无效答案。

分式不等式常用"移项通分"处理，把它化成"整式除整式"与零比较的形式，再列表判断符号。注意分母不能为零，所以解集里要去掉让分母为零的点。

绝对值不等式的处理思路是"去绝对值"。最常用的是分类讨论：想办法确定绝对值里面表达式的正负，然后按正负分情况去掉绝对值符号。另一种方法是两边平方，但只有在两边都非负的情况下才能用。

含参数的不等式是难点，核心是"分类讨论"。参数在什么范围内会导致解集形状变化，这个"分界点"通常来自：二次项系数是否为零、判别式是否为零、根的大小关系。分类讨论完一定要写"综上所述"，把各种情况合并成完整答案。

## 六、立体几何

空间几何体的表面积和体积公式要记牢。柱体的体积是底面积乘高；锥体的体积是三分之一底面积乘高；球的体积是三分之四 π r 的立方，表面积是 4π r 的平方。柱体和锥体差的那个"三分之一"经常搞混，我的记法是"尖的东西要除以三"。

线面关系的判定和性质是立体几何的核心。判定定理说"怎么证平行/垂直"，性质定理说"平行/垂直了能得到什么"。这两类定理成对出现，考试时容易用错方向。比如线面平行的判定是：平面外一条直线与平面内一条直线平行，则这条直线与这个平面平行。而线面平行的性质是：如果一条直线与一个平面平行，过这条直线的平面与已知平面相交，则这条直线与交线平行。

证明线面垂直的关键是"线垂直于面内两条相交直线，则线垂直于这个面"。注意"相交"两个字不能丢，如果面内那两条直线是平行的，结论不成立。

二面角的做法有三种：定义法（在棱上取点，分别在两个半平面内作棱的垂线）、三垂线法（利用三垂线定理构造出平面角）、向量法（求两个半平面的法向量，再求法向量的夹角）。向量法是万能的，但计算量大；前两种方法快，但需要一定的空间想象力。实际考试里我倾向先用几何法找找感觉，找不到就用向量法硬算。

空间向量是把立体几何"代数化"的工具。建立坐标系之后，每条直线可以用方向向量表示，每个平面可以用法向量表示。线线角用方向向量的夹角余弦的绝对值；线面角用方向向量与法向量夹角的正弦；二面角用两个法向量夹角的余弦，但要注意二面角可能是钝角，需要根据图形判断符号。这三处的"绝对值""正弦""符号"是最容易搞混的三个细节。

用空间向量法建系的时候，一定要选"三条互相垂直的棱"作为坐标轴，通常在长方体、正方体、直棱柱里最容易找到这样的三条棱。如果图形本身没有现成的三条互相垂直的棱，就要考虑先用几何方法证明出垂直关系，再建系。

## 七、平面解析几何

直线的斜率是解析几何的起点。斜率的定义是"纵坐标变化量与横坐标变化量之比"，几何上就是倾斜角的正切。要注意斜率不存在的特殊情况，也就是垂直于 x 轴的直线，它没有斜率。设直线方程的时候如果直接用斜截式，就会漏掉这种情况，所以做直线题时经常需要"分斜率存在和不存在两种情况讨论"。这个坑我在圆锥曲线压轴题上吃过亏。

直线方程有五种形式：点斜式、斜截式、两点式、截距式、一般式。点斜式最常用；一般式最通用（能表示所有直线，包括斜率不存在的）；截距式要求两个截距都不为零，所以适用范围最窄。选哪种形式取决于已知条件，但最终一般都要化成一般式方便比较。

两直线平行的条件是斜率相等且截距不等；垂直的条件是斜率之积等于负一。同样要注意斜率不存在的情况：两条斜率都不存在的直线是平行或重合的，一条斜率不存在一条斜率为零的两条直线是垂直的。

点到直线的距离公式要背：点 (x0, y0) 到直线 Ax 加 By 加 C 等于零的距离，等于 A x0 加 B y0 加 C 的绝对值除以根号下 A 平方加 B 平方。这个公式在做圆锥曲线的距离最值问题时经常用到。

圆的方程有两种形式：标准式和一般式。标准式能直接看出圆心和半径；一般式需要通过配方才能看出圆心和半径。判断一个一般式方程是否表示圆，要看配方后右边是否大于零。

圆锥曲线主要学三种：椭圆、双曲线、抛物线。它们的统一定义都与"到定点的距离"和"到定直线的距离"有关。椭圆的定义是"到两个定点距离之和为常数"，双曲线是"到两个定点距离之差的绝对值为常数"，抛物线是"到一个定点和一条定直线距离相等"。

椭圆和双曲线都有 a、b、c 三个量，但关系不一样：椭圆里 a 平方等于 b 平方加 c 平方，双曲线里 c 平方等于 a 平方加 b 平方。这两个关系特别容易记反。我的记法是"椭圆是大的那个在等式左边，双曲线是那个最长的斜边在左边"。离心率在椭圆里是 c 比 a 且小于一，在双曲线里是 c 比 a 且大于一，所以看到离心率大于一就知道是双曲线，这是判断曲线类型的快捷方式。

解析几何大题的通用套路是"设点、联立、消元、用韦达定理"。设直线方程，与曲线方程联立，消去一个变量得到一元二次方程，然后用韦达定理得到两根之和与两根之积。整个过程里最需要注意的是：联立之前要讨论直线斜率是否存在；联立之后要确认二次项系数不为零（否则不是二次方程，韦达定理用不了）。

## 八、概率与统计

古典概型的核心是"每个基本事件出现的可能性相等"。计算概率就是"满足条件的样本点数除以总的样本点数"。所以这类题的难点往往不在概率本身，而在"数数"——把样本点一个不漏一个不多地数清楚。列举法、树状图、列表法都是数数的工具。

排列与组合的区别在于"顺序有没有影响"。排列是有序的，组合是无序的。判断方法很简单：把选出来的元素换一下位置，如果算同一种情况就是组合，算不同的情况就是排列。这个判断一定要在动笔前想清楚，选错了公式整个答案就错了。

两个基本原理要分清：分类用加法原理（做一件事有几类办法，把各类办法数相加）；分步用乘法原理（做一件事要分几步，把各步办法数相乘）。"分类"和"分步"的判断依据是"做完其中一类是否就完成了整件事"。

二项式定理展开式的通项公式是：第 r 加一项等于组合数乘以 a 的 n 减 r 次方再乘以 b 的 r 次方。求"某一项的系数"就是让 r 取合适的值。求"二项式系数最大的项"要用组合数的对称性和单调性，中间那项或中间两项最大。

条件概率是"在已知某事件发生的前提下，另一事件发生的概率"。公式是 P(AB) 除以 P(B)。这里最容易错的是分母：不是总的样本空间，而是"已知事件"压缩后的样本空间。独立事件则是 P(AB) 等于 P(A) 乘 P(B)，也就是"一个发生不影响另一个的概率"。

离散型随机变量的期望和方差是统计部分的重点。期望是"加权平均"，每个取值乘上它的概率再求和。方差衡量的是"偏离期望的程度"，公式是"每个取值与期望之差的平方，乘上概率，再求和"。还有一个常用的简化公式：方差等于"平方的期望减去期望的平方"。这个公式在计算时通常更快。

正态分布图像的形状是"中间高、两边低、左右对称"的钟形曲线。均值决定曲线的对称轴位置，标准差决定曲线的胖瘦：标准差越大，曲线越矮胖，数据越分散。经验规则是：大约 68% 的数据落在均值加减一个标准差范围内，95% 落在两个标准差范围内，99.7% 落在三个标准差范围内。

统计里的两个核心概念是"抽样"和"估计"。简单随机抽样要求每个个体被抽到的机会相等；分层抽样是按某种特征把总体分层，再按比例从每层抽。用样本估计总体时，样本均值估计总体均值，样本方差估计总体方差，但样本方差的分母是 n 减一而不是 n，原因是要修正"用样本均值代替总体均值"带来的偏差。这一点课本上讲得比较简略，但考试不会考证明，记住结论就行。

线性回归是找一条"最贴近所有数据点"的直线。回归系数的计算公式本质上是"最小二乘法"的结果，也就是让所有点到直线的竖直距离的平方和最小。判断拟合效果的好坏看相关系数 r，r 的绝对值越接近 1 拟合越好，越接近 0 拟合越差。
